# OCR-NEA
This project was something that I done during A-Levels for a Non-examative assessment!
It's a scientific calculator with 5 modes: **calculate**, **statistics**, **graph & table**, **conversion** and **math box**
_This was one of my biggest projects i've ever done, not entirely perfect, but hey.. I got A grade :)_

_This project is stored here for archives_

# Requirements & Instructions
> [!WARNING]
> **This program uses alot of libraries and may require some for you to manually install**
> 
> With that in mind, there is a risk that some libaries may no longer work anymore

> [!CAUTION]
> Some code in the program (which is Developer Mode) <ins>are able to **dox your approximate location**</ins>. Additionally, it can open tabs of brainrot 2024 ish YouTube videos or Instagram reels on your computer
> 
> *Why you may ask? You can thank one of my friends who suggested the "skibidi code" easter eggs :3*

### Libaries
You will need the following libraries:
- `ip2geotools`
- `geopy`
- `urllib`
- `webbrowser`
- `time`
- `customtkinter`
- `tkinter`
- `PIL` (aka. Pillow)
- `statistics`
- `matplotlib`
- `numpy`
- `random`

### Images
As you will download the code, you will have a folder called `images`.
*This, as the name suggests, has all the images needed for the program*

Move the `images` folder to the `C:\` file location
> [!IMPORTANT]
> **This must be in the `C:\` file location, otherwise images will not render**

### Run it!
Once you've completed these steps, just run `NEA Scientific Calculator.py`!
